# 混合清单的内部边界：何时可以扣除重复活动

本文件是 [knowledge-base #32](https://github.com/tiangong-lca/knowledge-base/issues/32) 的开发与研究协议，不进入读者页面。起点是源码 Main `688c3d723926ec641f892d4cb2f6de835f78287f`，已通过 workspace #2224 / PR #2225 集成到 Main `82b9da14d5479b84d5965a07c302a7d8a466fcc3`。全书协调任务 #9 保持开放；这一单元不缩减已批准的八卷和附录范围。

## 从哪一个缺口开始

卷四 V4-04 要求把对象和数据连接成有明确规则的网络，并有连接算例和失败案例；V4-05 要求读者能复核方程、单位和求解。现有过程计算章已经展示物理反馈网络的求解。相邻的混合清单章则用六条论述解释截断、部门聚合、三类混合方法和重复计算。`cl-inv-double-counting` 记录了文献所述运输与能源覆盖重叠，以及另一方法扣除已表示商品流的思路，但尚未给出一个能从头复算的连接。

本单元的问题是：**在固定的一项产品或服务需求下，一种有原始文献依据的过程／投入产出混合方法怎样补入原先遗漏的上游活动，怎样确定哪一部分已经被过程系统表示，又在哪些条件下不能作表面上相同的扣除？** 不预设所有混合方法用同一种扣除算子，也不预设混合结果一定更准确。若细读改变了起始问题的表述，先记录触发证据与受影响论证，再调整案例。

## 预先界定的检索与取舍

先查已登记作品与私有缓存，再通过原作者、正式出版商、大学或法定机构仓储和 Crossref 身份元数据追踪。以已读再印章确实引用的原始方法和案例为向后线索，以针对该方法重复计算或截断误差的原始批评、检验或相反结果为向前线索。优先能辨认具体连接对象、公式／表格、数据定义和关键限制的原作。题名命中、引文计数、摘要、后继转述和软件宣传只能提出线索。

计划检索串包括原题名／DOI 与 `hybrid life cycle inventory`、`integrated hybrid`、`tiered hybrid`、`double counting`、`overlap`、`truncation`、`price basis`、`correction` 的有界组合；中文“混合生命周期清单 投入产出 重复计算 截断”，德文“hybride Ökobilanz Input-Output Doppelzählung”，日文“ハイブリッド LCA 産業連関 二重計上”。不设发文年下限；时间、语种、渠道、实际字符串、命中、取舍、失败和停止理由在执行后另记。计划不冒充已经执行的检索，不能从没有检得推断不存在独立批评。

先选择一个足以解释内部边界的实际方法，不把此题扩为全部 MRIO、所有数据库或当代各国价格表的搜集。若同一算法仍有关键缺项，追踪能改变实质判断的具体前置原件；若无法合法取得，保留哪一步不能复原。不同研究的问题或覆盖不同时，不以数量投票判优。原件、提取文本和图像留在允许的本地证据缓存；不付款、不联络作者、不更改账户、不绕过访问限制，不将第三方原件纳入公开仓库或下载物。

## 原件与数值检查

1. 明确需求、功能和计量基准。说明过程系统表示哪些物理交换，IO 部门或产品账户表示哪些交易及背景联系；同名部门不能直接视为同一活动。区分直接投入、经反馈产生的间接需求、环境清单以及已经表征的影响分数。
2. 把原方法的连接写成可检查的记录或方程：行／列各是什么，物理量与货币量如何换算，部门／产品映射、年份、价格口径、地区和进口边界怎样影响解释。只写实际适用的条件；原作没有披露的价格或转换不能补成史实。
3. 对同一项服务先写过程覆盖，再写直接相加会发生什么，最后按所读方法说明怎样处理重叠。逐项辨认相同的产品、交易或活动、已接管的边界和数量，检查非重叠部分是否仍被保留。若原方法并非简单相减，应以其真正的连接程序取代这个起始示意。
4. 用一个具体不相容情形检验判断，例如同一金额代表不同产品组合、不同价格层级，或部门平均包含过程边界之外的活动。展示错误处理如何传到活动量与清单，而不仅列一句“存在不确定性”。若无法辨认重叠量，保留条件情景或未知量，不凭结果碰巧相近宣称修正正确。
5. 数值来自原件时绑定实际选段、表格和载体；教学设定须逐项标出。优先与既有墙面服务需求相接，但保持已发布 CASE-WALL-CONNECT v1 和所有旧输入哈希。需要扩展时用独立版本／身份，不能把虚构价格、投入或范围冒充历史案例复现、现实价格调查或实际软件运行。

## 2026-11-05 原件、算术与结构决定

已有莱顿学位论文共 220 页，固定载体 SHA-256 为 `ddff0352d833b103fc45f6c78abad133defcafde7ddd579a465e65c6d2274670`。目录、第三章扉页及论文末尾作品表将第三章与第二章分为两项作品。第三章是 Suh 单独署名、发表于 *Ecological Economics* 48(4) 的论文再印本，DOI `10.1016/j.ecolecon.2003.10.013`。本次定位用学位论文的印刷页及实际 PDF 页。出版商与 Crossref 信息用于核对作品身份。第二章所对应的 M03、原刊提供的 PDF 和学位论文中的这份再印各有明确身份。

第三章提供了可复算的 1,000 片烤面包示例。两次独立转录检查了原始页面图像，按过程块、六部门背景、上下游连接与 CO₂ 强度求解。物理废物流改写为处理服务时，使用和供给两项记录变号。式 (28) 第二行第一列的印刷值为 −0.5，文字提取遗漏负号。有理数直接消元及分块消元一致。过程结果为 18.1 kg CO₂，完整 11 个平衡式的残差均为零，求得过程贡献约 20.026837588 kg、货币背景贡献约 9.988265197 kg，合计约 30.015102786 kg，与原文显示的 20.027、9.988 和 30.015 kg 相合。原始参数是作者设计的教学数值。

这项复算改变了章节结构。式 (31)、(32) 给出的背景技术系数和环境强度已经过扣除。附录 A1–A7 说明年度功能流、商品与产业映射、价格向量、供给表、使用表和环境账户的处理，但没有给出把这些原始年账转换成该组示例系数的全套数值。p57 对上游支出的说明使用生产者价格，p58 称背景系数采用消费者价格，尚缺数值调和依据。p64 再印式 A7 中价格对角矩阵在左侧，应用到一般的产业行、商品列表时仍需核准指标和价格所属坐标。保留这处待核问题，避免自行改印原公式或把推测列为正式勘误。

Agez 等人的泵例另有研究对象。2019 年在线、2020 年卷期的原文在单一过程上比较由部门平均配方估算上游补充的规则，报告 BPC 钢材补项 −0.39 欧元/台及可能误删基础设施用钢路径的问题。原页题名、作者、DOI 和页码一致，PDF 内嵌题名却指向 ODYM，采用实际扉页身份。原文 CC BY，选读和图像核查见读取登记。Jakobs 等 2021 年的数据库研究沿用这些方法，并引入贸易单价及代理分布，提供独立的价格与修正规则敏感性材料。其瑞士消费篮子表中的 HLCA 栏报告新增 IO 部分，Γ 与 Λ 的过程基准不同。Yang 等 2017 年的爆米花反例同时给出例内反转。Pomponi 与 Lenzen 的回应单独登记，约克大学研究资料库作者摘要给出其对网络联系代表性的异议，接受稿链接返回 403。摘要的固定 HTML 可核其主张，复验其完整矩阵仍待原件。

实际执行的检索及直接访问记录进入书目登记。四个主检索串同时提交，合并结果中有 Agez 原刊，逐条命中排名未知。中文结果含方法综述与投入产出表解释，德文结果含融资排放材料和混合动力车辆同词异义项，日文结果含 J-STAGE 行业应用、筑波学位论文与 NIES 3EID 说明。相关地区材料保留作线索，本单元的具体方程采用上述已读原作。另作回应题名与机构域名检索，返回的引用该文资料未提供目标稿。实际日期、选中版本、失败与还需核查的内容分别保留。

教学构造将原文已给的系数求解与原文未展开的年账拆分分开呈现。另设两家发电方与一家服务方，公开每笔虚构年度中间交易和直接排放。拆出具名发电方后，对剩余账目重新归一化，再以双向连接恢复跨界购销。更换服务方的送电供应者可保持部门总账相同，却改变满足同一项具名交付所需的活动。这个反例检验供应商身份辨认。归入同一部门、价格相同、两组方程各自平衡，都不足以确定那张发票属于谁。既有墙面案例只提供平整基底、涂料 A 路线的电力需求。新构造计算该电力子清单，原始账目和原论文复算分开保存。
