## 问题与已有依赖

本单元服务已批准设计 V5-03A，并连接 V5-04、A05–A08、A10。问题是：一份带有气体身份与排放时间的清单怎样经过大气响应、辐射强迫及温度响应形成特定指标？分子、参考分母、积分区间或观察终点分别保留什么信息？在同一清单上，改变气体约定、时间尺度、指标或校正版，哪些比较成立，哪些不再成立？

原件核读须首先区分 IPCC AR6 第一工作组第7章的正式出版稿、Final Government Distribution 草稿、补充材料、后续勘误及底层原始研究。保持 `work-ipcc-ar6-wgi-ch7-2021`、`work-ipcc-ar6-wgi-errata-2025-10-07` 及现有 derived reading 的身份；实际 PDF 是新增载体，不把旧摘录哈希改称 PDF 哈希。

已有墙体教学案例使用特定校正因子；电力案例解释历史 Cambium 版本的规定系数；乳业例证涉及排放清单估计；时间章节讨论排放时刻与共同日历终点。它们是不同的证据和模型依赖。先审查全部受影响 claim/evidence/reading/case 闭包，再决定是否修订；新版本不自动推翻历史分析或授权重写旧输入。

## 检索范围与选择规则

优先官方 IPCC / Cambridge 报告、原始期刊及补充材料、机构原件、作者版本库和固定归档。检索渠道为这些原始站点及网页索引；DOI、作者、标题、年份、页码和引用链用于核对，不把索引摘要当作全文。时间不设下限，前向更新截至实际检索日。中英文查询包括“全球增温潜势/全球温度变化潜势/气候指标 时间尺度/甲烷 化石 生物源 勘误”和“AR6 Chapter 7 emission metrics errata Table 7.15 Table 7.SM.7 / CO2 impulse response multi-model / GWP GTP carbon climate feedback / GWP star accounting criticism response”。沿实际原文参考文献回溯；必要时扩充原文术语并保留查询和排除理由。

初始候选是 AR6 正式 Chapter07、Chapter07_SM、官方 Errata，Joos 等2013的多模型 CO2 脉冲响应及补充材料、Olivié/Peters2013的模型选择影响、Gasser等2017的反馈处理，以及 Cain等2019和有明确对应对象的原始批评/答复。作者代码候选为 IPCC-WG1/Chapter-7 与其 Zenodo 版本。列入候选不等于已读、已采用、独立确认或可执行。

按实际问题纳入原始定义、数值参数、模型比较、独立观测约束或特定会计批评；记录共享模型/数据及机构谱系。排除无版本泛表、二手转载替代原文、不能确定数值对象的表格和只重复摘要的结论。元数据可用于发现或身份核对，不承担未经选读的科学主张。完整因子全集、所有气体和所有政策用途不在本单元的可验收声称中。

## 顺序与证据门槛

1. **原件与权限。** 从普通公开入口取得正式章、补充和勘误，记录 URL、重定向、HTTP 状态、字节数、SHA256、实际日期、标题/版权/版次/页码。核对日期是报告、印刷、更新还是取得日期。全文原件保存在非 Git 私有任务目录，不公开原 PDF、完整因子表或私有聊天。可下载不等于可再分发；需要付费、登录授权或来源不清时保留缺口，不绕过。
2. **选读与方法判断。** 对声明、方程、表注、条件及相关上下文记录印刷页和 PDF 索引；关键数学、表格和勘误页视觉核验。区分单位质量脉冲、持续排放/变化率、背景浓度、响应线性化、反馈、参考气体、积分和终点。标记文献实际支持、限制及未读部分；独立模型比较与观测约束分别评价。
3. **数值资格。** 在运行前固定每个输入的值、单位、对象、分母、版本、取整和出处，并给出独立预期/容差。重建一个实际披露的 CO2 响应及积分；检查选定主表/补充表/勘误单元格关系。来源不能闭合时记录差额和缺失参数，不从目标倒求未知量。不把非化石甲烷的氧化约定扩展为所有生物源碳的普遍中性。
4. **案例与反例。** 优先已冻结且气体身份、服务和时点适用的案例输入；否则明确新作者假设。固定清单，逐一改变所研究的指标选择。选择不同 CO2/CH4 构成或时序的对照只为检验比较含义，不预设必须产生排名反转。若讨论变化率指标，必须定义历史排放、边界、时间差及归属，不能把它作为一单位产品的静态系数；负计算值不能直接声称总温度下降。所有不确定性与截断边界明确。
5. **作者工件。** 核对代码/数据许可、提交和归档版本、运行依赖、固定输入与原始输出；先判断它实际计算什么。若只支持特定图或旧版，不声称复现更正因子表。可合法运行的选定 fixture 在预期冻结后执行，保存环境/输入/输出/摘要哈希；不可运行则记录原因并保留独立重建的正确身份。优先复用现有工具，不未经需要引入依赖。
6. **成稿与审查。** 写作在关键证据和数学门槛之后进行。连续正文说明对象和正向推导，再给差别、反例与适用条件；公式、符号和公开最小输入帮助读者复查。采用规范知识记录、实际载体引注和单章连续注释。源意、数值/代码、读者理解、实际浏览器/打印表现分别复核；没有人类专家审阅或实证验证时不暗示已有。过程与任务信息只留开发 Markdown。
7. **交付。** 运行必要验证、类型、构建、Docpact、独立审查和实际线上检查，维护本 Issue 与全书 programme9，再完成受审源 PR 和精确 root 集成。提交/推送有意义的协议、来源和成稿里程碑。记录并释放任务临时服务器、浏览器、容器/卷；必要原件、归档和长期 programme 工作树明确保留。

## 停止、修订与继续

单个来源出现权限限制或重复失败且无新路径时停止该路径，转入有证据的替代问题，不能降低身份/科学门槛。关键输入缺失时允许发布明确有界的部分推导，但须调整 Issue 中实际可完成的接受范围并保留缺口，不能把失败当成功。一次追索在原始定义、实际参数、版本更改、对照和反方问题均有明确处置且新检索不再改变本单元论证时可结束；这不意味着系统综述完成。

重大反证、载体冲突或数值差异触发协议修订，记录触发证据及旧/新问题，不删除负证据。若新的领域结论需要外部专家，保留限定而不冒充认证。全书仍继续其他气候路径、土地/生物多样性、臭氧、行业与全球制度、序章、八卷、十二附录和版次资格；本单元完成不关闭 programme9，也无需重复请求提纲批准。
