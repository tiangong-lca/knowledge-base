# 概念与原理驱动的跨体系比较写作

2026-11-14 用户明确：系统刻画标准、导则、学术论著、数据体系与软件在 LCA 概念和原理上的一致与不一致，是本书的根本出发点。事实与证据决定论断能否成立；机构地位不能替代判断。本文件将这项要求落实为后续选材、撰写和审读的方法。全书范围与授权由[全书目标](../lca-book-goal.md)承担，中文表达沿用[写作指南](readable-writing-and-teaching.md)，实际来源和出版守卫沿用既有契约。

本规则面向此后研究和修订。已完成的语言修订、原始输入和历史接受记录保留其真实范围；采用本文件不表示当前书稿已完成系统比较，也不改变现行科学记录或公开内容。

## 1. 每章从共同问题出发

先明确读者需要理解的对象、关系和困难，再选择能解释或检验它的来源。章的贡献应能表述为一个有条件的认识，例如：为什么两个数同为每千克却不可直接比较，怎样判断两个交换可以连接，什么条件下两种表示给出相同结果。

来源负责提供定义、规定、解释、推导、观察或反例。案例负责让关系可追随、可检验。历史负责说明问题和办法怎样形成。三者均有不可替代的作用，但它们的存在本身不决定章的中心问题或篇幅。基础概念的总体说明不能仅由一个软件的对象模型承担。

“从原理出发”仍须交代假设和适用边界。不能预设一种超越所有问题和用途的唯一 LCA 定义，再把其他体系的合法差异都判错。能从定义或假设推导的结果、需要观察验证的机制、由规范确立的要求和价值选择，分别判断。

比较是全书主轴，不要求每段横列机构，也不要求每章制造争议。历史章、专门方法解释和附录可以聚焦一个来源，但须交代它对主轴贡献了什么，相关比较在何处完成或仍缺什么。未发现实质冲突、只得到条件对应，也可以是有用结果。

## 2. 文献优先级依问题确定

先区分检索优先、引用适用与结论分量。重要标准、被广泛使用的方法包及经典论著应优先进入候选地图，因为遗漏它们可能使比较失去代表性；入选之后仍逐项评价具体证据。没有一条跨所有问题通用的“ISO 高于 EF、高校高于软件”排序。

| 所问问题 | 优先查什么 | 必须另外核查什么 |
| --- | --- | --- |
| 某规范在指定情境究竟要求什么 | 适用版次的原条款、定义、修订及其约束对象 | 适用范围、例外和规定强度；不能由导则转述冒充原条文 |
| 某导则怎样把原则变成操作 | 对应版本的操作说明、规则、案例及其依据 | 操作是否被标准要求、是建议还是特定制度选择 |
| 一个概念或方法为什么这样建立 | 原始方法论文、能展开推导的专著及重要批评和更正 | 假设、证明、经验支持、独立性及反例；学校名望不加证明力 |
| EF 等方法的具体结果来自什么 | 固定方法版本、参考包、基础模型、因子及匹配规则 | 方法规则、数据包与单个因子的角色，不能统称一种“权威结论” |
| 软件实际上怎样处理对象和求解 | 固定版本的手册、发行源码、输入与原生运行结果 | 手册承诺与已测行为的区别，设置、默认、转换路径和环境 |
| 一种模型是否可靠地描述现实 | 相称的观测、验证设计、独立复现及失败案例 | 适用总体、可识别性、混杂、外推和不确定性 |

在同一问题内，比较证据的直接性、方法适配、透明度、可复核性、独立性、代表性及反证承受能力。不能把这些维度加成一个自动总分，也不能以“多引几个机构”替代缺少的关键证据。公开可取得只是执行条件，不是学术分量；难以取得的关键材料应登记缺口，不以方便取得的资料悄悄取代。

规范的适用权威与命题的经验或理论支持应分开：某条规则可以在声明符合某体系时必须遵守，同时其选择依据、代价和现实适用性仍可批评。反之，某个模型有充分经验支持，也不自动成为某制度允许的核算规则。合规、数学一致、实现一致与现实有效各有判据。

## 3. 用一份比较记录组织研究

在已有任务或研究协议中，为每个关键问题保留一份简短记录；不为每个自然段复制表格，不新建平行的事实库。复用现有 claim、evidence、reading、mapping 和 gap 身份。正文采用自然论述，记录用于保持研究方向和审查依据。

| 项目 | 要说明的内容 |
| --- | --- |
| 问题与章的贡献 | 要辨明哪项关系；读者据此能做何种判断；前后章为何需要它 |
| 比较对象 | 现实对象、概念、规则、数据对象、实现或结果的哪一层；量、单位与参照是什么 |
| 比较双方及选择理由 | 实际作品／条款／软件及版本、用途、读过的位置；为何具有代表性，遗漏谁会改变判断 |
| 可比较的命题 | 分别重述双方的具体命题、条件、量词和规定强度；不能只列同名术语 |
| 对齐与不可对齐处 | 哪些对象、条件、边界、时间或输出相同；哪些转换需要附加假设 |
| 关系与证据状态 | 采用下一节的分类；将已检查、未检查、未取得、证据不足分开 |
| 差异的后果 | 会改变定义、数据连接、活动量、环境量、指标、排序或使用判断的哪一步；也可证明在给定条件下不影响 |
| 检验或反证 | 可复算的推导、受控输入、原生运行、观察或能推翻当前解释的具体证据；实际未做就明确写未做 |
| 作者判断与保留问题 | 哪方在何种问题下更有根据；什么是合法选择，什么是错误或未知；结论强度不超过证据 |
| 成文与修订 | 必需解释、关键反例放哪里；旧身份、引用和下游如何保留；哪些新证据会触发重审 |

同一数据、同一作者链或同一作品的多个载体不是多份独立支持。比较包的覆盖范围须在开工前说明，但可随证据调整；增加或删除对照者要记录理由。不能在看到有利结果之后才隐去一个不利对照。

## 4. 分开描述一致与差异

| 关系 | 可作出的判断 | 不能直接推出 |
| --- | --- | --- |
| 在所检范围内相同 | 对齐命题与条件后，共用某个定义、关系或操作 | 全领域共识、所有版本或所有输入等价 |
| 条件对应 | 在明确转换或假设下可相接、换算或得到同一结果 | 不加条件的同义或可互换 |
| 层级不同 | 规范概念、数据模式、软件实例或计算坐标承担不同作用 | 定义互相矛盾 |
| 目的或估计对象不同 | 归属、响应、总体均值、个体差异等回答不同问题 | 只凭数值不同裁决哪方错误 |
| 版本或传播不同 | 不同发行、更正、转述或采用范围可以解释差别 | 后版自动正确，或使用了一项因子便采纳整个框架 |
| 规则、文档与实现不符 | 在明确条款及固定实例／运行中发现不一致 | 某软件全部版本或某格式普遍有缺陷 |
| 经验估计或模型分歧 | 目标量可对齐，但估计或机制不同；检查假设、数据、误差、验证及反证 | 数值差异必然是逻辑冲突，或无法裁决就表示证据同样充分 |
| 真正不相容的命题 | 在相同对象和条件下不能同时成立，且已排除可识别的层级／版本差异 | 必须各占一半篇幅，或必能马上找到成因 |
| 价值或制度选择不同 | 不同目标、责任或取舍导致不同规则；可以分析其后果 | 单靠计算证明唯一正确的价值选择 |
| 暂不能判断 | 缺少原文、转换、运行或观察，指出尚不能完成哪项比较 | 各方同样可靠、不存在差异或已证明矛盾 |

这些分类可以并存：同一比较可能同时涉及版本变化、模型假设和证据不足，不要求给整章贴唯一标签。

先记录差异，再检验解释。一个共同输入下总分相同，不足以证明中间连接、全部流或所有情境相同；结果不同也可能来自目标、分母、条件或数据，而非理论冲突。应检查与问题相称的中间量，给出最小可辨别例或反例。实质分歧须在正文说明性质与后果，不能只埋在注释中。

## 5. 标题与正文共同调整

解释概念或原理的主章，优先以对象及关系命名，例如“流的身份与过程交换”“清单结果与评价取舍”。机构名、作者名、软件名和案例名通常放在来源归属、具体比较段或必要的副题中。

当研究对象就是某版指南、一个历史事件、一项实际研究或一条软件实现路径时，可以具名。标题须与其层级和范围相称：历史专题、批判性原典阅读、工具说明及特定研究案例不需要装成通用理论。当前网站细篇与合订书章要分别评判；不得只因出现 CML、ISO 或案例名就认定不合格。

把“CML指南中的评价与改进”改为通用概念题名，必须先检验其正文是否真正比较了该概念；原文仅支持 CML 的地方不能随题名一起扩成普遍命题。保留有用途的原典阅读，可以调整其在全书中的位置。只改名字、增加机构列表或把大量来源移到脚注，都不足以完成研究重组。

## 6. 把此前的修正变成可复用原则

| 已遇到的问题 | 后续写作的检查 |
| --- | --- |
| 把模型函数的试验说成网页界面能力 | 精确说出行为由哪个版本、接口和设置产生；文档、代码、运行各自取证 |
| 把地区／时期身份不同写成数值必然不同 | 区分对象身份、数值和可约去的条件，检查量词及反例 |
| 把同组活动量的平衡残差混同两组解的差 | 先写明比较对象、固定量和每一行单位，再解释抵消或差额 |
| 对来源署名或年份自行补出两项调查、独立证据或历史继承 | 所属作品、载体、调查与关系分别核对；缺证不补故事 |
| 用“连接”“职责”“原语”等省略具体关系 | 补出正在讨论的对象与动作；科学术语可以保留，工作记录口吻不进入正文 |
| 因语句顺畅改变归因、必要条件或否定强度 | 对照原命题的对象、分母、条件、归属与推断强度；新的限定也需要依据 |
| 修订题名后只改一处显示 | 核对两种阅读组织、目录、生成式导航、现行链接及旧题语境；稳定ID与历史范围分别保留 |
| 把有出处、可复算、读得顺或构建通过互相代替 | 分别评价证据支持、比较论证、中文表达、软件／出版完整性与全书研究覆盖 |

这些是关系检查，不是禁词表。语体采用平实、准确的中文学术叙述；短标题、句长和措辞变化不能凌驾于清楚的对象、逻辑和必要限定。一次更正只证明已处理的具体问题，不能称同类问题从此全部消失。

## 7. 执行时怎样防止偏离主线

每个任务开头用短段同时声明：本书的比较目的、本任务要解决的问题、实际产物与明确未覆盖部分。把“概念比较研究”“材料重组”“中文润色”“出版维护”分清；同一任务可包含多种工作，但不得以其中一项的完成替代另外几项。语言任务可以在固定科学记录内完成；缺来源或缺比较的章节则需要研究／重组任务，不能继续无限润色来补足。

研究先回答问题，再形成比较记录与正文样本，随后分别审查。代表性试点应包含真实差异或条件对应、有必要限定的段落、普通叙述及静态阅读；试点的目的在于检验方法是否可用。通过后再分批扩展，同时在每部和全书层级检查各章是否共同推进中心问题。已有已审单元只重查受新证据或新组织影响的范围，不为仪式重新读一遍所有无关材料。

审读分别回答五个问题：

1. 概念与比较：读者能否说明共同问题、双方具体命题、相同或不同的条件、后果及本书判断？
2. 来源与实质：原件、推导或实际运行是否支持该强度的判断，关键反证和未知是否可见？
3. 叙事与中文：段落是否推进认识，主体、指代、搭配、标题与承接是否清楚？
4. 出版与连续性：两种阅读形态、规范段、数值、注释、现行／旧引用是否匹配？
5. 全书覆盖：已完成哪个研究问题，哪些承诺还未覆盖，后续工作究竟补什么？

用实际稿件、可解释的前后对照和理解／迁移任务作证。审稿人应能举出文本依据，而不只是勾选通过。模型审读按实际范围记录；人类学习效果须由真实研究支持。题名数量、模型赞同、测试、哈希或交付状态不提供第五项研究完成证明。

每次交接同时写已得到的认识、尚存缺口及下一步的明确问题；将关键要求映射到具体段落或比较记录。修改改变命题或作用范围时，走现有证据、身份和下游复核流程；保持历史记录，不把上一轮接受当永久豁免，也不为新主线重设全部旧基线。

## 8. 后续首个试点：流、交换与边界

下表是研究设计，尚未实施或接受新的科学结论。先重核已有原件和既有实现记录，再决定是否需要新运行及合法补充来源。

| 共同问题 | 已有入口 | 下一步要补的比较与检验 |
| --- | --- | --- |
| 什么穿过了什么边界 | 现有 flow／exchange 定义与未连接废物流，农业施用量／环境净排放例 | 区分产品系统的截断／开放边界与技术圈—自然环境边界；说明未连接的技术流为什么不自动成为基本流 |
| 什么时候可把两条记录当成同一流 | openLCA 流定义、交换实例及 ILCD 已登记字段材料 | 物质／产品身份、介质、方向、性质、量、单位与参照各有什么作用；同名同单位仍可能不可合并 |
| 废物与处置服务如何表示 | 固定瓶子案例的两种编码和原生计算 | 区分物理去向、过程角色、编码符号和模型连接；检验条件对应而非预设一种普遍符号 |
| 参照流如何进入活动量和计算目标 | 现有功能参照、定量参考和独立目标的记录 | 对齐规范／指南用法、数据字段、软件求解，给出目标丢失或参照改变的具体后果 |
| 什么流能进入表征 | 现有零／缺失因子与环境路径材料 | 将流身份、环境归属、因子匹配、覆盖与结果分开；检查同数值能否掩盖不同证据状态 |

来源候选包括适用 ISO／GB 原条款、JRC/ILCD 与具体 EF 包、原理性专著和方法论文、所选工具的固定版本手册与运行。这里列的是职责，不是每行都必须凑齐这些机构，也不以固定文献数验收。ISO 原文未取得时，明确相应规范比较尚未完成；可以先完成有直接公开证据的有界问题。

试点应同时交付一份可审查的比较记录和一段自然成文的解释，既能展示现有材料怎样转成概念认识，也能暴露仍缺什么。之后优先沿“功能参照—过程网络—交换—混合清单”核对共同语义，再扩展共同生产／响应和影响指标。具体批次按科学影响、下游依赖和证据缺口决定；本设计不授权无证裁决或机械重命名。
