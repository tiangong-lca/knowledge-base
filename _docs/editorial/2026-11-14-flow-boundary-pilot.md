# 流、交换与边界比较试点

## 开始时的研究协议

用户于 2026-11-14 授权实施比较写作设计：先核实原始文献与各体系的比较，再写成完整、自然的中文正文，并独立检查概念一致、差异及其后果。执行任务为 [Issue 99](https://github.com/tiangong-lca/knowledge-base/issues/99)，更广研究范围仍由 programme 9 管理。当前源基线为 Main `0496e14e3b1e1e641382bdc23da6942fda4d38c2`；沿用独立工作副本，从该基线起 `codex/flow-boundary-99`，PR 回 `main`，后续另行精确根集成。

这是一项概念比较研究及成文任务。出版维护负责正确呈现研究结果，不能替代比较研究本身；此前 #95 只接受保义语言修改，不承担本轮新增科学判断。既有原生输入、实际执行回执、旧命题身份和历史接受范围均保留。

### 问题、材料与检验

| 问题 | 需要辨明的关系 | 优先证据与可能的检验 |
| --- | --- | --- |
| 什么穿过什么边界 | 研究系统的取舍与技术系统—环境划分；截断技术流与基本流 | ISO/GB 可合法取得的原定义、ILCD 2010 操作规定、CML 原理；用废物和田地检验两种边界是否被混同 |
| 何时是同一流 | 物质/产品身份与过程内交换实例；量、单位、介质和参照 | ILCD Format 1.1 原始模式、固定软件文档与来源数据；同名同单位的可合并条件 |
| 废物和服务怎样表示 | 物理方向、交易角色、过程参照和计算符号 | 原始理论论证、导则和既有固定瓶子原生模型；逐项核对处理活动、环境量，区分条件等价与普遍等价 |
| 参照怎样进入计算 | 规范/导则的功能参照、数据字段与独立求解目标 | 原定义、模式与已执行格式往返；目标改变与字段保留的不同后果 |
| 哪些量进入表征 | 环境归属、流身份、因子匹配、缺失与零 | ILCD、指定 EF 规则/方法包和既有原生因子控制；逐介质检查输入，而非仅比总分 |

各问题不强制列齐所有机构。来源按定义、规定、理论理由、数据表示、运行观察的实际职责选择。共同原作或载体不算独立支持。初步检索沿既有 reading/source 注册身份及原作参考链，使用官方 ISO/国家标准公开服务、JRC/EUR-Lex、原作者/机构与固定发行文档；检索词包括 elementary flow / system boundary / technosphere / reference flow / waste treatment / pesticide emission，以及基本流、系统边界、废物处理、农药排放。保留实际检索日期、查询、未取得与排除理由，不宣称系统综述召回率。

只把实际合法取得并读过的位置登记为核读。付费、私有授权或不可用原文保留缺口；公开书目信息不能变成规范条文证据。取得文件的 SHA-256 标识实际字节，网页/抽取文字/PDF/ZIP 成员分别保留身份。原件、原生数据库和原始输出不进入公开仓库。公共记录仅保存必要的原创转述、书目信息、定位和范围。

### 比较和写作次序

1. 先记录双方实际命题、对象、条件、版本与规定强度，分开理论、制度选择、实现和经验有效性。
2. 逐项判断相同、条件对应、层级/用途/版本差异、模型分歧、真正不相容或未知；不按机构排名，也不为形成争议而强判冲突。
3. 检查差异影响哪项输入、连接、活动量、环境量或指标。已有运行仅在原身份核验后复用；新设定明确为作者示例，不能冒充观测或软件行为。若能由符号推导充分辨明后果，无需为制造新回执重跑无关模型。
4. 独立审查比较记录，再写连续正文。主章按概念和推理组织；软件实例说明条件及后果，来源清单不充作章结构。正文可解释新的共同基础，旧案例细节按明确去向保留。
5. 分别审查原件支持、概念比较、中文理解和实际出版物。新上下文审读提供实际材料与版本，初评不提供其他审稿结论。DeepSeek 仅在配置可核验且能增加证据时使用；不把模型意见写成人类验证。

### 交付与停止条件

交付可审查的比较记录、阅读登记、完整书章及受影响细页/概念/论断/注释，另有独立接受的新出版单元。新的科学判断不能塞入语言修改豁免；早期基线、数值输入和负向守卫不重设。真实网页、连续书稿、打印、无脚本与键盘入口接受检查，旧引用保留原范围。

当五个问题已有可支持的回答或明确限定的未知，主要异议与反例均有处置，继续检索只会重复材料时停止本轮。原条款取得、重要不同版本、反例或原生结果不符将触发重审。本轮不承诺穷尽全领域、全部 ISO/GB 条款、所有软件或真人学习效果。最终说明所得认识和具体未覆盖问题；项目/构建完成不等于全书研究完成。

该协议先于本轮科学编辑提交；之后的实际取得、命题比较、审查与结论另列，不倒写成预先判断。
