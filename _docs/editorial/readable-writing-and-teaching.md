# 把 LCA 知识写成一本可研读的书

2026年11月11日经 [knowledge-base #91](https://github.com/tiangong-lca/knowledge-base/issues/91) 纳入仓库写作规范，适用于 LCA Living Knowledge Base and Review 的中文书稿，以及以书稿为基础的审读和教研。

新写、修订和审读书章时，按本文的解释组织、科学限定、数字与案例呈现、静态阅读和交稿复核要求工作。各章按论证需要选择写法。材料取舍、正文与注释、科学证据和出版验收同时遵守[全书目标](../lca-book-goal.md)、[编辑协议](../editorial-protocol.md)和[读者出版契约](../reader-publication-contract.md)。教研活动用于发现读者理解问题。评价试读效果需要真实读者表现记录。

原《可读性复评与后续写作、改稿、教研说明》是2026年11月11日的编辑建议稿 v1.0，SHA-256 为 `53930467eda8c06e6ff17f593e8f42ac89511f220ad5acb67d75ce9c893bee9b`。当时的评估、示范和审读边界保留在本文。章号、节号及引用文字均指复评使用的候选提交 `3d938f32bf25362973ded448807d302c4a0d0ef4` 的书籍输出。现行写作工作和实际交付状态见[执行记录](../book-execution.md)。

## 一、候选书稿可读性复评（历史记录）

候选书稿已经能在一些章节中把复杂问题讲清楚：读者看得到具体对象，跟得上关系的变化，也能知道一个数字为何改变判断。差距主要出现在另外一些段落：作者急于交代材料身份、计算细节和适用边界，读者却还没有弄清本段究竟在解释什么。于是文字虽然谨慎、有出处，却容易读成逐项核查的记录。

需要改进的是解释的组织。读者应能沿着一个问题，逐步认识对象、理解概念、跟随推理，并形成有依据的判断。来源、版本和限制要帮助这条过程成立。它们若与主论点同时涌来，且没有轻重之分，读者就要自行重建作者的思路。

“与人类书籍对齐”在这里指向一种具体目标：面向研究者、研究生和专业实践者，能够连续研读的中文学术著作。学术专著、教材、科普读物、史学著作各有文体，不能抽出一种共同口吻强制套用。也不能据若干词语、句型或长句比例，判断文本由谁写成。本说明讨论读者理解的障碍和编辑办法。

### 评估范围与可信边界

本轮采用两条独立路径。主评者检查了全书目录、七部的组织、全部40个单元的开头和结尾，并对交换语义、电力、水稀缺、毒性、数据质量与概率等相关段落进行重点复读；没有把这一覆盖说成再次逐字通读全部正文。DeepSeek Harness 在新会话中独立审读，报告按顺序读完40个单元，并抽查5个单元的注释。运行前通过界面核验 DeepSeek V4.1 Flash、Max 思考、完全权限及实际工作目录；初始任务未提供主评结论和前次报告。

这次复评覆盖前言、导论、32章、2个专题和4个附录。正文样本来自实际书籍输出，不以源文件数量代替阅读。审核用的 U/P 标记不是书中文字；非前置单元的 P001 是章题下简介，不能把它误当成正文第一段。注释文本投影压平了部分列表、表格与折叠结构，因此本轮不据此判断真实排版。没有进行真实读者实验，也没有重新验证所有科学主张及原始文献。

独立评估是发现问题的证据之一。主评者对建议作了取舍：采纳对象和动作不够具体、信息需要分层、跨章案例需要清楚标识等发现；不采纳“一章必须只有一个结论”“所有段落首句必须是主张”“版本和复算细节一律进注释”等硬规则。短章是否不足，要看它承担的任务是否完成；数学推导中的中间数值，可能正是理解的必要环节。

### 候选书稿的具体表现

| 位置与现象 | 对读者的影响 | 后续处理方向 |
| --- | --- | --- |
| 第8章讨论实例、连接、导入、需求与表征，部分总结又收束为多项检查问题 | 读者记住“还要检查什么”，却可能难以复述各案例已经证明了什么 | 先回收具体案例的发现，再说明检查方法；保留各结论的条件 |
| 第12章简介把交付电压、损失、小时电量、历史响应、资本变化连列 | 尚未读正文时，读者知道话题很多，却未必知道为什么要依次讨论 | 用本章要解决的供电判断串起材料；不必再列一次关键词 |
| 第18章从两处耗水算到3 m³和12 m³ world-eq. | 同一组数字把物理体积与模型指标分开，抽象区别有了可追随的过程 | 保留完整计算及单位解释，可作为方法章的正例 |
| 第27章杯重调查从总体定义、抽样设计走到均值精度 | 概念有经验对象；但连续多组小数可能增加记忆负担 | 保留关键运算，用文字或小表区分“个体散布”“平均值精度”“来源不一致” |
| 第29章先用等质量比较制造错误，再恢复相同服务 | 读者看见错误发生在哪一步，理解比较条件的理由 | 保留这类反例；说明它是教学设定，不转述成真实产品优劣 |
| 第29章静态输出仍出现“上方控件”“滑块步长”等文字 | 脱离网页后，读者可能寻找不存在的操作对象 | 为静态阅读提供完整的参数、范围和解释，界面操作另列 |
| 第14、23、24、26、31章相对简短，承担若干重要概念区分 | 可能需要更多解释才能独立使用这些区分；单凭篇幅无法定论 | 用试读任务查明具体缺口，再决定补例、补推理或明确导读功能 |

同时应保留已有的有效写法：第7章用两个虚构过程说明反馈遗漏，第13章从一张纸的后续用途引出实物过程与负担分担，第22章从政策问卷走到权重，第30章让读者看见审查意见怎样改变研究解释。它们提供了不同的叙述节奏，不应被改成同一套章法。

## 二、先让读者看见正在讨论什么

### 1. 具体对象在前，抽象概念随后获得含义

“对象、关系、连接、条件、边界、口径”都是有用的词，但它们不能长期替代正在讨论的东西。写“关系发生变化”时，应当能接着说清：变化的是工厂采购量、过程之间的供给、排放进入环境的路径，还是数据文件保存的字段。

一个实用的改稿办法，是在草稿旁问：“这里到底是什么，做了什么，或怎样随另一个量变化？”如果必须翻回数段才能回答，就应补回名称或调整顺序。无需机械地给每句加一个人类主语；模型、变量和物质也可以成为清楚的主语。但在责任归属重要的地方，要区分研究者提出建议、软件执行操作、标准规定要求和本书作出判断。

例如，第8章说明两个电力实例共用一份电网数据，其中一个服务铁路，另一个服务注塑和清洗。这句话不一定构成语法错误；但在一段已有多个对象时，重复一次“实例”比让读者猜“各自”所指更稳妥。具体名词的必要重复，比为了词汇变化而更换术语重要。

### 2. 每个新概念都有进入的理由

不要只告诉读者“接下来介绍某概念”，还要让他知道此前的问题在哪里卡住了。服务要求已确定，为什么仍需参考流？排放量已算出，为什么仍需环境模型？均值已得到，为什么还要区分标准差和标准误？这些问题可以自然引出术语。

首次出现的术语应交代本处含义、与相近词的区别，以及后文怎样使用。英文缩写服务于检索和精确对应，不承担解释本身。对于同名而含义不同的词，尤其要保留语境。比如“边际”在不同模型中未必指同一种运算，不能用一个通用释义覆盖全书。

已建立的术语不应频繁换同义词。中文更自然，通常来自准确的动词、清楚的指代和合理的信息顺序，而不是删除术语或增加口语。

### 3. 让已知信息带出新信息

“这”“其”“上述结果”只有在先行内容明确时才省力。若所指是一整组案例，应简短重提案例及其发现，再进行比较。段落开头尤其不宜要求读者记住很远处的一串对象。

同样，条件、年份、文件名与字段名全部堆在句首，会推迟读者理解本句动作的时刻。有时应先说明“这里要检验年度电量能否闭合”，再给出发布包、情景和行号；若版本本身就是争议对象，则应先说明版本。信息顺序取决于当段的任务。

Gopen 与 Swan 的科学写作讨论把读者预期和信息安排联系起来，反对以简单缩短句子代替解释。可借用这一编辑视角，但其分析对象是英语科技写作，不能把英语句末重音等规则直接当作中文定律。[阅读原文](https://www.cs.tufts.edu/comp/150FP/archive/george-gopen/sci.html)

## 三、段落要推进解释，章节要完成任务

一个段落可以提出问题、说明机制、展开计算、比较证据或收束判断。定稿时应能说出它主要完成了哪项工作。如果一段同时塞入文献沿革、模型定义、数值复算、软件实现和适用限制，就检查这些内容是否真需要读者同时处理。

“一段有一个中心”不等于每段只能有一句主张，也不等于每段都要采用“主张—证据—限制”。历史叙事可能把判断留到材料展开之后；推导可能必须经过数步才得出结论。段落的组织应让推理容易跟随，而不是让编辑规则一眼可见。

相邻段落之间要有认识上的推进：后一段为什么在这里出现？它解决了上一段留下的问题，还是引入了反例、转向另一个尺度？连续出现“某文献指出”“另一文献提醒”，还没有形成论证。作者需要解释这些材料之间是补充、矛盾、范围不同，还是尚不足以比较。

章末应回收本章已经获得的认识。一个检查清单可以作为工具，但不能总是代替结果。例如，读者不仅要知道文件转换应检查目标、单位和连接，也要知道本章所考察的转换究竟保存了哪些信息、在哪条具体路径上出现变化，以及这些发现何时适用。一个章节可以形成多个相互关联的结论；无需强行压成一句。

现有结尾也不能只因最后一行是导航而被判为“没有承接”。例如第6章在导航前已经讨论服务要求如何转成过程需求，第25章也已引出不确定性。改稿应读完整个收束段群，避免重复添加“下一章将……”造成新的模板感。

### 不同章节应允许不同的推进方式

| 章节任务 | 读者需要的组织 | 常见失败及修正 |
| --- | --- | --- |
| 历史解释 | 当时的问题、参与者能取得的材料、所作选择及后续变化 | 年份排列不自动构成因果；把后来评价与当时立场分开，不虚构场景或心理 |
| 数学与模型 | 所求量、定义与单位、假定、必要步骤、结果解释 | 公式列表缺少“为什么算这一步”；补关系说明，保留关键推导 |
| 方法争论 | 各方回答的问题、主张、依据、分歧所在及后续回应 | 不能仅交替摘述各方观点；说明究竟争论事实、模型、目标还是价值选择 |
| 完整案例 | 研究任务、共同参照、数据与模型、运算、判断、变化条件 | 小例子过多却无一走完；选择能持续追踪的案例，旁例承担明确的对照任务 |
| 综合与展望 | 回收此前认识，说明尚未解决的问题及什么证据能改变判断 | 不以泛泛愿景替代综合，也不为“完整”新增没有依据的预测 |

章首可以从问题、研究中的困难、已有说法、实际史料或一个简短演算开始。选择取决于内容。不要把“开章三句”“一章一结论”“每节一案例”变成新指标。

## 四、限定要放在它改变判断的地方

科学限定是论证的一部分。编辑时先问：如果读者漏读这条内容，会把哪一项结论理解错？

会改变结论含义、适用范围或推断强度的条件，应留在正文，并靠近相应主张。若整段建立在同一组假设上，可在展开前集中说明；如果后文改变了其中一项，应当明确提醒。来源争议、版本变化和舍入问题也可能直接改变判断，不能仅因形式像“细节”就搬进注释。

不会影响当前理解、但有助于追索的页码、文件路径和重复定位信息，可以进入注释或附录。主文应留下足够的对象身份与引用，让读者知道依据在哪里。抽离细节后，应重新检查主张还能否被正确解释。

例如，第27章27.3节的分层路线：按报告的均值5.6474 g与均值估计方差0.0034 g²计算，相对标准误约为1.0325%，与来源后续讨论所写的0.07%不一致。这一差别会影响“复现了调查精度”的主张，因而应在正文说明；完整算术可以另附。它与下文示范二的整群路线不同：后者计算出的约1.50%与来源显示值相合，不能用这一相合覆盖另一处不一致。反之，同一案例已经清楚声明为虚构演算时，不必在每段结尾重写一遍完整声明；在独立引用、换情景和得出应用判断处，仍需提供足够提醒。

“没有取得原始数据”“文献没有提供原始数据”“原始数据不存在”是三个不同的陈述。修辞简化不得越过这些区别。同样，“尚不能辨别差异”“未证明等效”和“已经证明差异很小”不能相互替换。

避免连续以泛泛的“不能推广到现实”收尾。更有效的写法是说明当前结果支持什么，以及要回答下一问题究竟还缺什么。第32章已经指出，即使不能给出总体优胜者，仍可能识别负担集中的环节或值得追查的假设。这种有条件的正面认识，应当成为读者能够带走的内容。

## 五、数字与公式应帮助读者推理

一组数字是否该留在正文，首先取决于它在解释中做什么。数字可能展示量级、完成推导、揭示错误、比较情景或验证来源。小数位多并不自动等于冗余；小数位少也不自动等于自然。

开始演算前，明确要算什么，量的分子分母各指什么，输入来自观察、文献还是教学假定。运算中说明关键变换的理由。运算后解释数字意味着什么，并把结论留在这些条件之内。可以省去重复的机械算术，不能省掉读者学习概念所依赖的一步。

OpenStax 的《大学物理》量纲分析一节先说明量与单位，再通过问题展开检验；《统计学导论》的样本均值一节将所讨论的随机变量、公式和练习联系起来。这里借鉴的是解释的功能，不照搬形式；量纲一致也不意味着 LCA 中的服务、物质和模型语义已经相容。[量纲分析](https://openstax.org/books/university-physics-volume-1/pages/1-4-dimensional-analysis)；[样本均值](https://openstax.org/books/introductory-statistics-2e/pages/7-1-the-central-limit-theorem-for-sample-means-averages)

### 区分三种精度

原始来源的显示值、计算时使用的精度、正文为了阅读而作的舍入，应分别说明。正文写“约”不能悄悄改变底层输入。完整复算值可以保存在可查的表格或计算材料中，正文保留足以支撑判断的位数。若恰好研究舍入造成的差异，就必须展示相关数位。

第27章的杯重例值得保留：均值5.6589 g与均值估计方差0.0072 g²，先得到标准误，再得到相对标准误。若删掉方差和开方，只留下“约1.5%”，就破坏了读者理解标准误的机会。可以将读者显示值写成标准误约0.0849 g、相对标准误约1.50%，但需保留来源值、计算依据和它描述的是平均估计精度这一含义。

有多个相近数字时，可用一张小表分别标明估计对象、统计量和单位，再回到连续文字解释。表格承担查找和比较，正文承担推理。不要让读者在十多个小数之间自行记住哪一个描述个体，哪一个描述均值。

### 让贯穿案例携带自己的条件

同一案例跨章出现时，应给它稳定名称，明确是完整案例、简化片段还是改变条件后的对照。首次提前使用后文的案例时，在当前段提供理解所需的最小设定，并指向完整说明。不要只写“按原设定”，把阅读者送到尚未读过的章节寻找条件。

案例索引可以登记：研究对象或服务、虚构或经验来源、固定条件、各次改变的条件、首次完整说明和后续用途。它帮助作者保持一致，但不应成为正文开场的又一张填表任务。10 m²的墙面简例与100 m²、十年服务的完整例，尤其不能混作同一设定。

## 六、改写示范

这些局部示范出自复评。评估时没有将示范应用到书稿，也未进行科学复审。示范保留相关事实和推断边界；正式采用时还应核对上下文、引用和计算材料。

### 示例一：把抽象介绍变成有内容的问题

第18章18.1节原文节选：

> “从一个具体耗水量出发，在具名模型的背景和参照下，计算潜在的其他用水者受剥夺程度。这条联系值得逐步展开，因为物理水量、模型背景与环境指标各自承担不同的工作。”

可改为：

> AWARE把耗水量与当地的水资源背景联系起来，评价这项耗水使其他人类或生态系统用水者缺水的潜势。因此，读到“耗水3 m³”时，还要问这项耗水发生在哪里，以及所选因子采用什么背景和参照。接下来的计算将说明，同样的耗水体积为什么可能得到不同的指标结果。

改动集中在信息顺序：“具名模型”“各自承担工作”变成这一模型具体评价什么。保留“潜势”，不把指标改写为已经观察到的损害；方法版本与参考期仍须在后文对应位置说明。

### 示例二：留下推导，减少同时记忆的数位

第27章27.3节原文节选：

> “取平方根，标准误约为0.084853 g；再除以平均值，得到相对标准误约1.4995%，与原文显示的约1.5%相合。”

与前句连写时，可呈现为：

> 整群路线报告的平均杯重为5.6589 g，均值估计的方差为0.0072 g²。对方差开方，得到标准误约0.0849 g；再除以平均杯重，相对标准误约为1.50%，与原文显示的约1.5%相合。它描述平均杯重估计的相对精度，并不表示每只杯子都只在平均值附近变动1.5%。

这里改变的是读者显示值，关键输入和两步运算仍在。完整复算记录应保留更多位数。不能把“均值估计的方差”缩写成含义不明的“杯重方差”。

### 示例三：先解释一次复核要判定什么

第12章12.7节包含年度电量与表列负荷相差−7.2 MWh的复核。可以先用一句话标明任务：

> 这些公开的年度电量能够近似闭合，但不足以重建原始求解精度。以同一发布包的MidCase、ERCOT、2025行为例，区域发电加进口减出口得到437,697,372.8 MWh，表列母线负荷为437,697,380 MWh；前者比后者少7.2 MWh。这个差额应当保留，不能因为两项总量接近，就把近似闭合写成精确复现。

这是对原段已有判断的提前说明。这里的2025是模拟年，相关说明应继续保留；不要把年度表改称实测电量。若本节任务是教读者重算收支，三个输入量仍应在正文或紧邻表格中列明，不能只剩一个汇总数。

### 示例四：让静态文字能够独立阅读

第29章输出中的“滑块步长未必取到交点”和“不随上方控件变化”依赖网页界面。静态版本可围绕同一数据解释：

> 在共同参数θ的给定范围内，差值的精确配对范围为[−0.438, 3.562]；θ＝0.1438时差值为零。若把两方案各自的边际极端直接相减，得到的范围更宽，因为这种算法没有保留共同参数关系。

交互版本可以另行提示滑块取值。静态正文仍须保留差值定义、θ范围、单位和共同服务；不能只抄这一小段便认为说明完整。下载链接作为读者获取复算材料的入口可以保留，无需一律删除。

## 七、把正文、注释与教学材料各自写好

正文应让读者在不频繁离开页面的情况下，理解本章主要论证。必要的依据与限定留在叙述中。注释提供精确出处、异文、材料范围和补充解释；附录容纳较长推导、完整复算及专业读者需要的细节。复杂或关键的概念不能仅因难写就移入附录。

网页可增加交互、检索、下载和交叉导航；打印或离线阅读应有自己的完整表达。学习目标、计算步骤和软件操作也可能属于优秀教材，不能见到它们就判定“不是人类书籍”。判断它们是否适合当前载体和章节任务。

教案和课堂讲义可以使用预测题、暂停提示、讨论问题和教师答案。书稿无需处处模拟教师授课，更不必在每段末尾替读者提问。后续教研应从已经写清的论证中设计活动，再把真实误解反馈给书稿。

Living 的要求也不意味着正文随处显示维护状态。修订记录应说明新证据改变了哪项判断，旧结论在什么条件下仍成立。当前正文应形成可连续阅读的版本；修订历史、出处和计算材料让这个版本可以被检查与更新。

## 八、后续写作与改稿流程

### 写之前：确定读者需要完成的认识

作者先按全书目标第2.13节明确本章的问题、依据和拟交付判断，用几句普通中文说明读者已有何种知识、读后应能解释或判断什么。随后选择材料：哪些构成主要证据，哪些用于反例，哪些只供查证。文献数量不等于解释深度，发现更多材料也不必立即增加一节。

历史章先核对事件与文本身份，模型章先画清数量关系，争论章先列明分歧所在。对于还缺依据的环节，保留具体研究问题；不要用顺畅的过渡句遮盖证据缺口。

### 写之中：先形成论证，再检查每项主张

可以先写连续叙述，再补齐精确引用；但引用整理不能延后到失去原始出处。关键主张须能回到材料，作者演算、教学假定和来源结论要区分。段落合并或重排后，应重新核对引用作用范围，不以“引用仍在附近”证明它仍支持当前句子。

同一事实不必以同样措辞在多章重复。为了独立理解而重提时，说明此次讨论它的目的。不可把旧段落的数量和归属当作必须守恒的对象；应保留的是有效论证及可追溯关系。

### 改之后：分开检查真实性与可读性

第一遍检查科学与来源：对象、单位、分母、数值、条件、作者归属、推断强度和引用是否保持。第二遍暂时不追着引用走，连续阅读正文：是否知道每段在解释什么，是否需要无理由地回读，案例是否先有设定再被使用，章末是否回收了认识。

这两遍不能相互替代。文字更顺但含义改变，仍需返工；证据完备但理解困难，也没有完成编辑。模型可用于发现问题和提出备选表达，最终按具体证据裁定，不以多个模型赞同作为验收。

正式改稿时，同步维护受影响的主张记录、引用、算例与修订说明，并按仓库流程审查交付。

## 九、教研怎样检验“读懂了”

教研需要观察读者能做什么。主观“流畅”“像书”可以记录，但不应独自决定结果。建议让目标读者完成以下几类任务：用自己的话复述一个判断，重建关键关系，找出会改变结论的条件，再在稍有变化的情景中使用它。允许合理的不同表述；不把复述作者措辞当作理解。

### 一项可试用的颗粒物教学活动

材料取自第17章17.1节的历史因子连接。开始前让学习者说明“排放质量”和“人群合计吸入质量”的区别；这一步用于发现先备知识，不计作记忆测验。

题面给出：在书中对应的历史模型与排放原型下，城市近地初级PM₂.₅的吸入比例为44 mg吸入/kg排放，默认效应因子为78 DALY/kg吸入。该汇总因子的年龄、死因与人口权重沿用书中设定，不另作重新拼装。请完成：

1. 将44 mg/kg改写为kg吸入/kg排放，并算出表征结果。
2. 解释相乘时消去的kg与最后留下的kg各指什么。
3. 说明44为什么不是“44%的人口受到影响”。
4. 保留同一效应因子，将吸入比例改为书中乡村原型的3.8 mg/kg。结果怎样改变？这个比值能否称为实测城乡健康损失倍数？
5. 指出本例尚未完成的一项经验验证，以及它影响哪类判断。

教师参考：44 mg/kg＝0.000044 kg吸入/kg排放，乘78得到0.003432 DALY/kg排放；相乘时消去的是吸入质量的kg，结果分母留下的是排放质量的kg。44 mg/kg表达两种质量之比，不是人数之比，也不是44%的人口。乡村原型得到0.0002964 DALY/kg排放。城市与乡村比按44/3.8约为11.58。此处效应因子固定，比值来自吸入比例的变化，不是实测的城乡健康损失倍数。78这一因子的总吸入量分母包括所有年龄，而未满30岁的效应在该构造中设为零；这项覆盖约定不表示儿童没有健康影响。算式重建发布因子的连接，没有用新观察验证其健康关系。第5题可接受的回答包括：缺少用于重新验证健康关系的观察，因而不能把乘法相合当作新的经验验证；也可指出将历史原型用于特定现实地点还需相应证据。只要准确说明缺什么及其影响，不要求唯一措辞。

判读答案时分别记录错误：质量单位换算错误、分母身份混淆、把模型指标当实测结果、遗漏模型覆盖条件。它们需要不同的讲解。一个算对但解释错误的答案，不应与一个解释清楚但算术失误的答案合并成同一种“没读懂”。

### 怎样组织一次试读

选择有代表性的章节片段，并记录参与者的LCA、数学和专业背景。先提出开放问题，再让其阅读和作答；需要时请其指出卡住的位置。避免先解释主评者认为哪里不好，否则会把试读变成寻找预设缺陷。

区分读者缺少先备知识、正文解释不足、指代歧义和题目本身不清。为具体问题修改一处，再以相同能力要求检查；可使用平行情景减少机械记忆。若要主张教学效果或比较两个版本，需要另行设计样本、测量和对照，不能从几个试读意见推出普遍效果。

试读记录可以采用下面的简表，不设置自动总分门槛：

| 记录项 | 应记录的内容 |
| --- | --- |
| 文本与读者 | 版本、章节、阅读范围；相关先备知识 |
| 任务 | 要读者解释或判断什么；可接受答案及理由 |
| 观察 | 实际回答、停顿或回读位置；必要的短原话 |
| 初步解释 | 可能的文本问题或知识缺口；尚不确定之处 |
| 修改与复查 | 改动、保留的含义、再次检查结果、仍未解决的问题 |

涉及学习者记录时，按实际教研安排告知用途并尽量去除身份信息。试读材料与正式研究数据应区分，不能把未经同意的反馈直接用于公开案例。

## 十、给后续作者与审稿人的简短任务书

以下文字可复制到写作或审稿任务中，再填入具体章节和工件：

> 面向能连续研读的中文学术著作，处理指定章节。先说明本章的问题、读者先备知识和应获得的认识。依据实际文本定位阅读障碍，说明它为何妨碍理解，并提供保留事实、单位、条件、出处和推断强度的修改方案。优先使对象、动作、关系、信息顺序和段落推进清楚；允许历史、推导、争论和案例采用不同写法。不得以词频、篇幅、长句比例或作者身份判断质量。可构造并明确标注教学算例，说明假设与用途；不得把虚构内容当作真实证据，不得杜撰来源或历史心理。数字按其论证作用处理，重要限定靠近相应判断。检查跨章案例与静态阅读是否独立可理解。区分已观察的问题、推测与风格选择，并提供能让真实读者检验理解的任务。没有实际试读时，不声称学习效果已经验证。

交稿前至少回答下列问题；某项答不清，应记录具体位置，而不是只勾选“通过”：

- 读者能否说明本章在解决什么，并找到已经形成的判断？
- 每个关键概念是否有具体含义、进入理由和足够的解释？
- 数字、公式与案例是否帮助推理；对象、单位、假设是否可辨？
- 限定是否防止了具体误解；移走细节后，主张是否仍准确？
- 段落之间是否推进认识；是否只堆放了文献和检查事项？
- 改写是否保持了来源归属、条件和推断强度；引用范围是否重新核对？
- 所称“读懂”是否对应实际任务表现；哪些效果仍待检验？
