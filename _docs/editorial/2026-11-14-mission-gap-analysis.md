# 现有书稿与跨体系比较目标的差距

本次诊断以已交付 Main `0c8382182497e6110ac349c26f0139a21ae38008` 为书稿基线，核查目标与写作要求的 Git 历史、全部现行目录、流相关规范段与证据关系，并以功能参照、共同生产和评价框架的实际内容作对照。两项独立只读审查分别检查概念组织及要求—执行关系。本轮没有重新通读全部原典、重跑所有软件或改写公开书稿；以下是有范围的编辑判断，不是新的科学对比结论。

## 1. 差别主要在研究组织与验收对象

现稿已经形成一条从服务、过程和清单走向环境影响、数据与判断的阅读路径，也有真实的比较、反例、未决问题和作者综合。当前不足是这些比较尚未系统地支配各个基础概念的选材、定义入口和章节产出。用户要求把标准、导则、学术论著和软件在同一概念上的一致、分歧及其后果，提升为全书主轴。

| 层面 | 现稿的实际表现 | 距离本次明确目标尚缺什么 |
| --- | --- | --- |
| 概念基础 | 部分入口直接采用某工具的数据对象定义，注释虽有限定 | 先建立问题与对象，再说明不同层次的定义、表示及相容条件 |
| 选材 | 已做大量原件与实现核查，但材料分布受已取得作品和案例影响 | 按关键问题选择代表性对照者，说明重要遗漏，使用已有而未进入综合的证据 |
| 比较论证 | 若干章节能解释不同目的、条件对应和错误实例 | 形成跨章可追踪的命题级比较，区分哪些是共用基础、真正不相容或尚不能判断 |
| 题文关系 | 合订本章题大多已经概念化，少数网页仍按来源组织 | 检查中性标题下是否仍主要讲一份资料；具名专题需有明确分工 |
| 验收与报告 | 有实际来源、读者、语言及出版审查，工程证明很完整 | 把“该比较问题已得到什么认识”列在首位，避免用审校覆盖和发布完成替代研究覆盖 |

因此需要研究补缺和论证重组，继续逐句润色不能独自完成这一差距。旧单元的实际交付和保义检查仍成立；新的总目标评估不应将它们说成毫无价值，也不能把其范围扩为系统比较已经完成。

## 2. Flow 的问题可以具体定位

`knowledge/catalog.json` 中 `cn-flow` 的唯一定义入口是 `cl-flow-type`，内容为 openLCA 2 手册中的 flow 数据对象；`cl-exchange`、`cl-flow-exchange-distinction` 也从同一工具的记录方式解释流与交换。它们本身明确了来源范围，不能因入口偏窄便将其判为错误。概念索引及交换章的正式流定义段以该工具为入口；交换章虽先有实物情境，这一正式入口仍不足以承担全书普遍概念基础，读者还需要明确的跨体系关系。

不能把这个发现扩大成“全章只引用 openLCA”。[短专题](../../content/docs/flows.mdx)还讨论 Brightway 的符号／图边；[交换语义章](../../content/docs/book/exchange-semantics-and-conversion.mdx)已有 ILCD/JRC 原文件、特定 openLCA 原生运行和格式转换材料。具体版本的运行资格与手册说明仍须分开。

更有诊断意义的是：已经登记的 `ev-kb50-jrc-doc-flow-type` 指向 `rd-kb50-jrc-ilcd11`／`psg-kb50-jrc-doc-flow-type`，其记录提到 ILCD 的 Flow 类型及参考属性；当前没有 claim 直接引用这条 evidence。这表明，至少一项已登记选读的 ILCD 流类型材料尚未进入流概念入口的对照，仍须判断其独有作用。登记中的三类／四类差别可作为重核候选，不能未经原件对齐就声称 ISO 与软件冲突，或宣称不同枚举项可以一一映射。

下一步应让读者能区分：物理传递与数量，研究系统的开放边界与技术圈／自然环境边界，可复用的流定义与一次交换，产品／废物角色与矩阵符号，参考对象与求解目标，以及基本流与表征因子。现有未连接废物流、目标丢失、零与未匹配因子的反例都可服务这些问题；是否扩成跨标准结论仍取决于实际对读。

## 3. 题名问题不能靠删机构名解决

按当前 `config/reader-numbering.json` 核对，合订本的 32 个正文章题没有直接列机构或软件名；网站 37 篇中的一个题名是《CML指南中的评价与改进》，对应合订本第 4 章已叫《评价框架与分析步骤》。未在当前题名中查到用户所举措辞的逐字形式，故以实际题名为诊断对象。

网站这篇的原典、版本及接受史阅读有独立用途，可以具名。然而合订本第 4 章的铝箔、椅子、包装及筛查接受材料仍主要沿 CML 展开。若其任务是解释“清单、评价、改进、解释怎样产生可辩护的判断”，就须让其他体系在相同分析任务下接受比较，并说明各方的假设、工作产物和反馈关系。换成一个通用标题而不补正文，会把来源特定的认识扩成未经支持的普遍主张。

可供后续试稿检验的题名如“清单结果与评价取舍”“评价结果与改进判断”；并非本轮已经批准的改名。具名接受史、实际研究案例及附录仍可保留专有名称。机构／案例可否进入标题取决于它是不是研究对象，而非一张禁词表。

## 4. 现有有效比较值得保留

[功能参照章](../../content/docs/book/service-and-reference.mdx)把共同服务、方案参照和过程资料分开。`cl-book-cml-reference`、`cl-book-ilcd-reference`、`cl-book-reference-reading` 根据对象、用途和换算条件解释两份指南的用语差别，没有直接宣布条文矛盾；`cl-book-comparison-more`保留 CML 转述不能替代 ISO 原条文的边界。

[共同生产章](../../content/monograph/joint-production.mdx)让同一批输入分别回答份额归属和路线比较。`cl-joint-what-additivity-proves`说明质量和收入份额都能合账，但加总不裁决采用哪种归属；`cl-joint-rival-criteria`区分不同文献实际回答的问题；`cl-joint-different-questions`说明同单位的数仍可能代表不同对象。这种“同题—条件—后果”的组织可以复用，不应全部推倒。

交换章已有 `cl-native-representation-result` 的条件对应，以及 JRC 具名文件／实现中的具体差异；框架章有 `cl-cml-balance-caution`、`cl-cml-methane-counter` 的原件内部或采用结果不相合。它们证明稿件并非只做机构背书。问题在于尚未形成足够完整、分层且可用于概念判断的比较网络，部分结论仍停留在个别材料的核查。

## 5. 原要求、后续细化与本轮澄清

| 阶段与可核记录 | 当时已有的要求 | 本次诊断 |
| --- | --- | --- |
| 11-04 获批基线 `a9ae501f`，目标§1.1、REQ-02/03/07、§1.3、§2.4及研究单元 | 中文学术著作、真正含义、跨体系关系、证据胜于机构权威、不同层次分别检查 | 核心方向早已清楚，不能把欠缺都归给用户最初未说明 |
| 11-06 `e5df5ed` 与 11-08 `c6d569b` 的著作化和材料取舍要求 | 连续论证、作者判断、前后承接、来源不自动取得正文席位、共同点／真分歧／未知 | 后续反复出现逐篇陈列、核查口吻和材料挤占主线，属于执行未稳定落实 |
| 11-11 写作指南与 11-13 `77c2d54` | 具体对象、信息次序、平实准确中文、搭配／指代／题文相称、独立语言审校与完整部样本 | 这些规格逐步细化；不能将后来确定的题名用词或审读顺序回溯为早期已违反的硬要求 |
| 11-14 本轮 | 把跨标准／导则／论著／软件的一致与不一致设为统领目标，明确来源优先级与概念题名 | 将已有方向进一步置于研究拆解和验收的首位，不止增加一般性提醒 |

早期目标的主问题较广，围绕 LCA 的形成、分化和使用；跨体系含义已经贯穿研究要求。今天把系统比较明确为根本出发点，是重要的重心澄清。准确判断是：原有核心要求没有充分落实，具体文体和优先顺序后来又被进一步明确。要求逐步精化是正常过程，执行者应整合新旧约束，而不让用户反复承担方向校准。

早期设计中“短名词短语、概念主张或意象”的表述，也给过度压缩和抽象命名留下空间。它与后来的平实、准确、对象清楚存在张力。现行规则应明确概念与题文关系优先，意象是可选手段，不能同时把它当作必须满足的风格目标。

## 6. 漂移怎样发生

以下是由所审样本及留存工件支持的过程解释，不推测隐藏的模型动机，也不把这些样本视为对所有章节的穷尽归因。[11-08 取舍方案第6—7节](2026-11-08-argument-and-selection.md)记录重复和细史挤占论证的实例；[写作指南中的历史复评](readable-writing-and-teaching.md)记录具体阅读障碍；[#93 读者报告](review-evidence/complete-readable-book-20261112/reader-report.json)与[#95 协议](2026-11-13-chinese-expression.md)说明各轮实际审读和接受范围。

- 评价框架等样本的组织显示，已取得的原件及可复算案例可能成为工作包中心，使“读完这一份材料”被误用为章节的自然边界；这是一项由样本支持的过程推断。
- 来源核对和不可变守卫对防止失真很有效，但有界语言修订刻意固定成员及科学记录，无法同时补齐尚缺的比较研究。把这种边界长期当作写作组织约束，会阻碍新综合。
- 标题概念化不必然改变正文重心；逐段改顺也不必然形成跨来源的论证。
- 已对实际稿件进行独立读者视角审查，包括 DeepSeek 模型审读，并非只有机器验收；但审查问题主要验证可理解、保义和连续阅读，未以足够具体的代表性对照来验证全书的系统比较使命。
- 交付报告突出段落数、测试、地址、哈希与合并状态，容易让研究目标的缺口退居次位。它们应继续作为各自范围的证明，不再充当研究完成度。

执行方应承担任务定义、审读问题和完成表述的校准责任。上一轮 #95 的语言修订与发布事实保留，但不足以证明用户在本轮强调的根本目标已经实现。后续交付要先说明获得了什么认识和哪些关键比较仍缺，再报告工程完整性。

## 7. 已记录的规则与后续边界

[比较写作契约](concept-led-comparison.md)统一规定问题依赖的来源优先级、命题对齐、差异分类、后果检验、作者判断、概念标题及五项独立审查。写作指南吸收此前的修正原则，目标与执行入口引用同一套规则，避免各自复制一份逐渐漂移的清单。

下一步选择“流、交换与边界”作为研究／成文试点，先补比较记录与概念解释，再据实际反馈扩展。它不是预定结论，也不是给现有 openLCA 文字补几个机构引用。当前 ISO 授权原文及部分版本映射缺口仍须明确，公开材料可支持的比较先有界推进。本次只交付诊断和可复用设计，没有声称已经完成该试点或全书重组。

### 本轮外部核查的范围
