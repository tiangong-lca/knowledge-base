# 服务要求、过程表示与约束保留

## 开写前的问题与范围

[任务102](https://github.com/tiangong-lca/knowledge-base/issues/102)是2026-11-15持续 GOAL 的首个科学单元，采用[比较写作契约](concept-led-comparison.md)。从已合并的规则更新 Main `10dc686fe9316dbb42b91adefe821d9e55ea4e29` 开始；该版科学内容仍与试点 Main0fd2c7b 一致。源分支 `codex/service-constraints-102` 回 `main`，另需精确根集成。原件探索已先于本协议发生，下面明确记录其结果；本文件先于公共正文改写提交，不冒称盲法预注册。

共同问题是：同一项服务已经表达成模型的数量要求以后，换一种记录方式是否仍保留原约束？哪些变化只重设坐标或基准，哪些映射会把原来不平衡的活动也判成平衡？“所有数字换算正确”还不足以说明现实服务已被模型充分表达，后一个问题仍需功能、性能和使用资料。

主成文目标是 B07《过程网络》。B06已有 CML／ILCD 的实质参照比较，B08已经写出正对角列缩放与某条原生路径的目标丢失，B09已经有同部门账但实际供应者不同的反例。这些只作前提和对照，不作为本次新结果；仅按实际影响复核相邻章、概念、注释及后续消费者。

## 对齐命题与代表材料

1. **可逆表示。** 对固定的活动集合、技术流身份和同一目的，比较 `As=f` 与 `RA s=Rf`。可逆 R 是保留平衡约束的充分条件；与 B08 已有的列基准 D 分开。对某个具体模型，非可逆映射也可能只删掉冗余条件，不能把“非可逆”直接写成必然改变其解。检验的是有没有原非零残差被映射成零，不是单看两个总分。
2. **原作的零价服务。** 核读 Heijungs、Settanni、Guinée（2013），*Toward a computational structure for life cycle sustainability analysis: unifying LCA and LCC*，[DOI10.1007/s11367-012-0461-4](https://doi.org/10.1007/s11367-012-0461-4)。作者先用自然单位的活动表求解，再据相同活动核成本和增值；不能把它误说成直接从货币方程唯一解出服务，也不能据此否定所有货币分析。原例是设定模型，没有真实椅子市场或使用效果的测量。
3. **约束恢复。** 针对原例说明保留原服务行及需求，或另有足以推出同一约束的经核信息，能恢复什么；名称、一个零值或事后任选活动量不能单独完成恢复。凡物量、目标、价格、活动集合或用途改变，另行检查是否仍是同一问题。
4. **功能与数值需求。** ISO2006已取得的公开原条款、ILCD2010的方案/产品参照及现行字段记录用于区分功能要求、过程量基准和需求坐标。具体引用只用实读范围，不将预览升级为完整修订版。若扩展到 PEF 的制度要求，需明确选择理由、原文范围与新认识；不为补机构名而扩写。

论文的实际固定载体为 Bath 提供的13页 VOR PDF，含库封页；SHA-256 `7c86b8c184e44989c0be6d43b413b7da32cdbf80ed47050d3b907360f42112b3`。封页的2026-11-14下载日期不是作品年代；网上先行与2013卷期分开。封页及文末声明 CC BY，原始文件留私有证据区，仅登记必要出处、原创解释及事实。主要选读 §§3.1–3.2 的设定、Tables1–4/式(5)–(15)，§3.5/式(20)–(22)，Table6与结论的相关位置；不称全篇、原始 LCC 文献或 CMLCA 执行已核。

## 探索已经发现的冲突与不得省略的检查

初次矩阵核对及独立原件复核发现：式(10)报废椅行／处置列印为20，而按式(5)和(9)所声明的价量变换为2，式(12)及对应表的缩放贡献也与后者一致。两套字面输入的残差和解不能混在一起。原文还出现木材/电力成本名称与对应表互换的叙述；其合计不变，不能用合计相符替它证明逐项无误。原刊 HTML 也需逐式核对，独立载体一致仍是同一作品的证据，不是独立模型验证。

这些当前是有定位的内部不一致观察，不是已经查获的正式勘误，也不能推断全部版本或作者软件都同样错误。正文若采用，必须分开原文印值、按原文声明关系重建的值和本书进一步推导，并说明哪项结论受影响。以原作定义的价量映射研究失去服务约束时，不能同时把物量解说成满足字面20版本的金额方程。没有取得补证时保留未知，不私自修正原件。

检查选取最少能辨别问题的内容：原作物量平衡与逐行单位；原价量映射与原文印刷矩阵的差额；零活动和给定服务活动在各自方程中的不同状态；保留服务条件后的恢复；一个只删冗余条件仍可保持解的作者控制例。用有理数或可审查符号推导避免显示精度掩盖问题。若没有新的软件行为主张，不为本单元重跑既有瓶子或其他引擎。

## 成文、审查与停止

先形成可反驳的比较记录与数值/符号依据，独立检查核心命题，再写自然连续正文。读者应能回答“原来要求的服务去了哪里”，并分清表示等价、改变所问对象、丢约束和源中表项不一致；不能只背可逆矩阵条件。源义、实际阅读、出版与全书覆盖各自签收，保留必要反例和来源的合法不同用途。

原有正确段落和输入不为凑改动而重写；有据的新增或纠错各有明确身份和历史处置。新科学接受不能冒用试点99的许可。实际章节/注释/概念/导航/下载及两代受影响消费者全部按真实变更核对；需改变旧守卫时，以精确继任和故障反例证明保留的责任，而非刷新基线跳过检查。

当共同问题具有可支持的有界答案、关键反例有处置、完整稿能供读者使用且实际交付资格成立时，本单元可结束。原书的全书研究与其它批次继续进行。正式勘误、不同原版、能区分机制的原生或经验反例，以及新稿暴露的理解缺口将触发对应问题重审。访问不成功不被写成不存在，也不阻塞不依赖该来源的独立任务。
