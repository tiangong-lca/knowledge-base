## 系统重建的限度 [#明细表能否重新组装总量]

<Prose ids="cl-hist-assembly-check" />

下表列出原报告给出的两套系统总量，并将 OWG 的原报总量与按第二卷 Table 8 所列分项重算的总量对照。两项 OWG 总量均以一百万次灌装为基准，但依据不同，应分别辨认。

| 数值的来源与对象 | 数值 | 单位或换算 |
| --- | --- | --- |
| 原报告：10-RET整体能源 | 2026 | 百万Btu／百万次灌装 |
| 原报告：OWG整体能源 | 6036 | 百万Btu／百万次灌装 |
| OWG十三项显示分项之和 | 29.102 | 百万Btu／短吨系统基准 |
| 分项和乘205短吨 | 5965.910 | 百万Btu／百万次灌装 |
| 报告整体值减显示分项组装值 | 70.09 | 百万Btu／百万次灌装 |

此处百万次灌装均为每次十二液盎司。表中差额是6036−29.102×205；它定位了尚未闭合的组装关系，没有给出差额的成因。
