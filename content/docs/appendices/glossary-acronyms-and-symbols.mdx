## 检索入口与跨章同名符号消歧 [#检索与消歧说明]

本附录作为全书的随手检索工具，汇总正文中反复出现的数学符号、62 组（共 110 个）高频中英缩略语以及十二组最易混淆的核心术语对照。若需查阅全书全部概念的逐条定义、别名与支撑文献，请直接访问交互式[概念索引](/concepts/)；若需横向比对不同体系对同一概念的规则分歧，请参阅[概念 × 体系总表](/docs/appendices/concept-framework-matrix/)。

跨部阅读时，有四处同名缩略语或数学符号在不同语境下含义完全不同，切勿混用：

- **`EF`**：在制度与方法体系语境下指**欧盟（EU）环境足迹（Environmental Footprint）**（如 EF 3.1），在颗粒物与化学毒性表征链条（表征因子 `CF` 等于吸入分数 `iF` 乘效应因子 `EF`，即 `CF = iF × EF`）中指**效应因子（Effect Factor）**。
- **`A` 与 `B`**：在第二部清单矩阵运算（`As = f`、`g = Bs`）中分别指**技术矩阵**与**干预矩阵**；在第三部欧盟循环足迹公式（CFF）中则分别指**材料回收分担因子（0.2–0.8）**与**能源回收分担因子（默认 0）**。
- **`R₁` 与 `R₂`**：在欧盟循环足迹公式中指**再生料输入比例**与**报废回收率**；在 Ekvall & Tillman（1997）多级回收级联模型中则指**第一、二轮回收工艺环境负担**（与原生负担 `V₁`、最终处置 `W₃` 并列）。
- **`S_j` 与 `s`**：小写 `s` 在清单求解中指**过程活动倍率向量**（在 Cain 等 2019 年基于排放速率变化的增温当量指标 GWP* 公式中标量 `s` 指存量权重 0.25），大写下标 `S_j` 则指全局灵敏度分析中的**一阶方差分解灵敏度指标**。
